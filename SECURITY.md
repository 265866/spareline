# Security policy

## Supported versions

Only the latest release gets fixes.

## Report a vulnerability

Report it privately through
[GitHub](https://github.com/265866/spareline/security/advisories/new), not in a
public issue. Include the version, what you did, and what happened, and leave secrets such as
tokens and keys out of the report. You get a reply within 7 days.

A fix lands on `main` and ships in the next release.

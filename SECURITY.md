# Security

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/265866/spareline/security/advisories/new) rather than in a public issue. Include the version or commit, what an attacker can do, and the steps to reproduce it.

spareline controls real phones and stores the texts they receive. Run it behind a private network or an HTTPS reverse proxy, and never expose the app's port directly to the internet.
